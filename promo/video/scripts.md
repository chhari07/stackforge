# Video scripts

Record on the phone with the built-in screen recorder. Light mode, no notifications,
a neat clock. No face or voice needed: on-screen captions tell the story, because
Reddit, Instagram and YouTube all start videos muted.

Export **9:16, 1080p, under 60 seconds.** Use quiet background music that's free to use
(Instagram and YouTube have their own libraries; for Reddit use music with no copyright).

---

## 1 · The main video (Reddit, X, LinkedIn): 35 seconds

| Time | On screen | Caption |
|---|---|---|
| 0–3 s | Splash logo animating → welcome card "Stack makes you remember what you read." | **I forget everything I read. So I built this.** |
| 3–9 s | Chrome article → Share → Stack. "Saved to Stack" card pops up over Chrome | **Save from any app** |
| 9–16 s | Open a study PDF, select a line → Highlight → it appears in Notes with "from page 42" | **Highlight a line → it becomes a note** |
| 16–23 s | Today → daily review card "3 things you highlighted" → tap Got it | **Every morning, 3 come back** |
| 23–28 s | Select a hard line → Explain → answer in Hindi | **Explain anything, in Hindi too** |
| 28–32 s | Quick cuts: focus timer with music, home-screen widget, Library shelves | **Focus timer · widget · works offline** |
| 32–35 s | Logo on a plain background | **Stack · free · open source · no ads** |
